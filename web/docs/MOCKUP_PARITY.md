## Honest differences and limitations

- Real report text, counts, dates, geographic maps and photos differ from fictional demo fixtures. This changes content-dependent card height and density.
- Government connectors have no configured delivery adapters. The UI exposes their actual unavailable state and provides usable exports; it cannot claim successful government delivery.
- The server cannot know reports still stored on disconnected devices. The dashboard shows received reports and known offline-origin submissions rather than an invented global sync percentage.
- Labels-off mode uses the map provider's labels-free layer. There is no authoritative village-boundary dataset in this repository; no boundaries are fabricated.
- Facility labels come from actual facility records. Empty/error states are visible when no usable coordinates are available or the endpoint fails.
- External tile availability affects visual map completeness. Satellite attribution identifies its provider.
- Existing authenticated account, user/category/unit management, AI console and alternate submission routes have no desktop mockup scene. They are retained as infrastructure, not claimed as pixel-matched mockup pages.
- A complete screenshot pixel-diff comparison across every dynamic record/state has not been established. The four dashboard dimensions above are measured exact matches, and paired scene screenshots support visual review of the other compositions.
